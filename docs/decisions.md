# Design decision log

## ADR-001 — One integrated Fleet environment

**Date:** 23 November 2026  
**Status:** Proposed / to validate

We will maintain one reviewed Fleet project, with Marco and Riccardo as primary integrators. Other members contribute skills, policies, synthetic data, tests, research and documentation through GitHub and Drive. We prefer individual invitations rather than distributing a shared password. Fleet limitations, costs and actual capabilities must be checked before committing to a tool design.

## ADR-002 — Controlled memory and knowledge curation

**Date:** 23 November 2026  
**Status:** Proposed

A case-history entry is not an authorized policy. Curator improvements are drafted as versioned, reviewable skill changes, approved by a human before use. Formal policy is never silently rewritten.
